# 1. 개요

## 1.1 제품 비전

HARU는 부모와 아이의 하루 15분 책 읽기를, 4대 내적역량(감정 조절 · 자기주도성 · 회복탄력성/인지 유연성 · 내적동기)을 키우는 대화 루틴으로 바꾸는 Parenting Intelligence 서비스다. AI 시대에는 코딩·계산 같은 기술적 지능(Cognitive Intelligence)보다, 불확실한 상황을 견디고 질문하며 스스로 움직이는 내적 역량이 아이의 미래를 결정한다. 내적 역량은 "언어"와 "양방향 상호작용"을 통해 3\~9세 골든타임의 일상 대화와 책 읽기 속에서 길러진다.

HARU는 아이에게 화면 시간을 더 주는 Child-facing Screen App이 아니라, 부모의 대화 역량을 높이는 Caregiver-facing Dialogue Coach다. 서비스 전반에서 부족·진단·장애라는 단어 대신 관찰, 신호, 성장 힌트, 다음 대화 방향이라는 언어를 사용한다.

|           |                                                                                |
| --------- | ------------------------------------------------------------------------------ |
| **구분**    | **내용**                                                                         |
| 서비스 유형    | 모바일 앱 기반 Storytime Coach / Parenting Intelligence Service                      |
| 핵심 메커니즘   | 책 읽기 + 대화식 독서 + 녹음/체크 기반 관찰 + 4대 내적 역량 프레임워크                                   |
| 핵심 경쟁력    | 자연스러운 녹음 유도 UX, 책 기반 대화 Prompt, 4대 내적 역량과 연결된 성장 가시화                           |
| 미국 시장 포지션 | Child-facing screen app이 아닌 Caregiver-facing dialogue coach — 부모의 대화 역량을 높이는 앱 |
| 초기 언어·현지화 | 사용자 노출 언어는 영어 1차. 본 문서는 승인용 국문 PRD                                             |

## 1.2 배경 및 문제 정의

양육자는 다음과 같은 어려움을 겪는다.

  - 대화 부재 — 양육자와 아이의 대화 자체가 줄어 내적 친밀감 형성이 어려워지고 있으며, 어릴 때부터 Screen Time 의존도가 증가하고 있다.

  - 교육 목표·방향 부재 (Goal & Capability) — 큰 변화의 시대에 무엇을 교육해야 하는지, 성취해야 할 역량과 판단 기준을 알지 못한다.

  - 대화 주제 부족 (Content) — 어떤 주제와 질문을 던져야 아이와 대화가 이어지는지 알 수 없다.

  - 실행 방법 부재 (How-to) — 역량을 키우기 위한 매일의 일상 속 방법과 수단, 기준(Criteria, Science)이 없다.

각 문제를 제품 과제로 번역하면 다음과 같다.

|           |                                           |                                                     |
| --------- | ----------------------------------------- | --------------------------------------------------- |
| **문제 영역** | **고객 현상**                                 | **HARU가 해결할 제품 과제**                                 |
| 대화 부재     | 양육자와 아이의 깊은 대화 시간이 줄고, 스크린 의존도가 높아진다.     | 책 읽기 시간을 자연스러운 대화 루틴으로 전환한다.                        |
| 교육 목표 부재  | 미래에 필요한 역량이 무엇인지, 어떤 기준으로 성장을 봐야 하는지 모른다. | 4대 내적 역량을 부모가 이해 가능한 언어와 시각화로 제시한다.                 |
| 대화 주제 부족  | 책을 읽어도 어떤 질문을 해야 대화가 깊어지는지 알기 어렵다.        | 책 · 아이 기질 · 선택 역량에 맞는 대화 Prompt를 제공한다.              |
| 실행 방법 부재  | 좋은 교육 방향을 알아도 매일 실천하는 방법이 없다.             | Today's Activity Card, 알림, 읽기 완료 체크, 4주 리포트로 루틴화한다. |

## 1.3 제품 목적

  - 4대 내적역량(① 감정 조절 능력 ② 자기주도 역량 ③ 회복탄력성·인지 유연성(메타인지) ④ 내적동기부여)을 기준으로 아이의 현재 수준을 파악할 수 있게 한다.

  - 일상에서 "책 읽기"와 읽는 동안의 "대화"를 결합한 대화식 독서를 통해 언어로 교육할 수 있게 한다.

  - 아이에게 개인화된 대화 Prompt와 책을 추천하고, 아이에 대한 분석(Insight)을 제공하는 "우리 아이 맞춤 Parenting Intelligence · 나침반 · Human Development Infra"가 된다.

  - 궁극적으로 4대 내적역량의 성장을 "눈으로 확인"하고, 양육자-아이의 내적 친밀감을 증대시킨다.

## 1.4 핵심 가치

**책은 매개체, 대화는 메커니즘, 4대 내적 역량은 성장 나침반이다.**

|                                 |                                                                                            |                                             |
| ------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------- |
| **가치 축**                        | **사용자에게 보이는 가치**                                                                           | **제품 기능으로 번역**                              |
| Personalized Conversation       | 오늘 이 책으로 아이에게 어떤 질문을 하면 좋을지 바로 알 수 있다.                                                     | 책 추천, 질문 2\~3개, 부모용 코칭 문장, Follow-up 질문     |
| Parenting Intelligence          | 우리 아이가 어떤 기질과 관심을 보이는지 누적해서 이해한다(BI와 유사한 개념 — 아이를 키우기 위한 Intelligence 전반). 4대 내적역량 Status. | User Contributed Profile, 세션 로그, 페르소나       |
| Building Child Inner Capability | 아이의 4대 내적 역량을 키워주고 방향성을 알려주며, 수치 데이터로 확인하게 해준다.                                            | 다이아몬드 그래프(Compass), 역량 스냅샷, 변화 히스토리, 4주 리포트 |

## 1.5 시장 포지셔닝 및 확장 경로

  - 1차 타겟 시장 — 미국 B2C 부모/양육자 시장. 이후 고용주 복지(Employer Benefit) → 유치원·초등 저학년 기관 → 치료/튜터링 네트워크로 확장 가능.

  - 경쟁 서비스의 한계 — 부모를 대체하는 Child-facing 플랫폼은 아이의 흥미 지속이 어려워, 흥미가 떨어지면 리텐션이 무너지고 다시 부모를 끌어들여야 하며 수익성 유지가 어렵다.

  - HARU의 회피 전략 — 양육자를 직접 사용자로 설계(Caregiver-facing)하여 아이의 흥미 변동에 대한 의존도를 낮추고, 부모의 대화 역량과 루틴에 가치를 집중한다.

# 2. 목표 및 성공지표

## 2.1 MVP 핵심 검증 가설

  - 가설 1 (지불 의향) — 부모가 "오늘 이 책으로 아이에게 어떤 질문을 해야 하는가"라는 문제를 돈을 내고 해결하려 한다.

  - 가설 2 (녹음 신뢰) — 부모가 녹음 유도 UX를 감시가 아닌 "소중한 대화 시간의 기록"으로 신뢰하고 실제로 사용한다.

  - 가설 3 (루틴 형성) — Activity Card와 알림만으로 주 3회 이상의 대화식 독서 루틴이 유지된다.

## 2.2 제품 목표

  - 양육자가 가입 후 10분 이내에 온보딩 설문을 완료하고 첫 Activity Card(책+Prompt 추천)를 받는다.

  - 가정당 주 3회 이상 대화식 독서 세션을 습관화한다.

  - 4주 리포트를 통해 성장을 가시화하여 장기 리텐션을 만든다.

  - 아동 음성 데이터를 안전하게 처리하여 양육자의 신뢰를 확보한다.

## 2.3 핵심 성공지표 (KPI)

MVP(베타) 기간의 목표치는 절대 수치 대신 베타 테스트를 통해 기준선을 수립한다.

# 3. 타겟 사용자 및 페르소나

## 3.1 주요 사용자

|                |                                                                                                                        |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **구분**         | **정의**                                                                                                                 |
| Primary User   | 미국 내 3\~9세 아이와 책을 읽는 부모, 조부모, 베이비시터, 튜터, 치료사 등 직접 양육자. 계정 소유·설문 응답·리포트 열람의 주체. 책 읽기를 좋아하는 Heavy User, 책을 구매할 여력이 있는 층. |
| Secondary User | 3\~9세 취학 전후 아동. 앱 조작 주체가 아니라 대화 참여자이자 관찰 대상. MVP UX는 아이가 아니라 양육자를 직접 사용자로 설계한다.                                        |
| Early Adopter  | 교육·SEL·책 읽기에 관심이 높고, 아이와의 대화를 더 잘하고 싶지만 구체적 질문과 방법을 모르는 부모.                                                            |

| 신뢰 장벽          | 아이 음성 녹음, 발달 분석, 감정 해석은 민감하다. MVP에서는 진단의 언어 대신 Parent Insight, Storytime Reflection, Conversation Guide의 언어를 사용한다.     |

# 4. 4대 내적 역량 프레임워크

4대 내적 역량은 HARU의 성장 나침반이다. 각 역량은 Storytime(대화식 독서) 상황에서 관찰 가능한 신호로 측정하며, 추천 대화 방향은 Prompt 라이브러리의 설계 기준이 된다.

|              |                                    |                                              |                                                 |
| ------------ | ---------------------------------- | -------------------------------------------- | ----------------------------------------------- |
| **역량**       | **정의**                             | **Storytime에서 관찰 가능한 신호**                    | **추천 대화 방향**                                    |
| 감정 조절 능력     | 불편한 감정, 좌절, 무서움, 슬픔을 견디고 말로 다루는 힘. | 감정 단어 사용, 어려운 장면에서 멈추지 않고 대화 지속, 감정에 이름 붙이기. | "이 장면에서 마음이 어땠을까?", "그 마음이 몸에서는 어떻게 느껴질까?"      |
| 자기주도 역량      | 지시받기 전 스스로 선택하고 질문하며 이어가는 힘.       | 아이가 책/질문을 선택, 이전 주제를 다시 꺼냄, 읽기 후 행동을 제안.     | "오늘은 어떤 장면을 다시 보고 싶어?", "다음에는 네가 질문을 하나 만들어볼래?" |
| 회복탄력성·인지 유연성 | 틀림, 변화, 모순을 견디고 생각을 다시 조정하는 힘.     | "하지만", "다르게 보면", "왜 그럴까"처럼 복수 관점 표현.         | "둘 다 맞을 수도 있을까?", "처음 생각과 지금 생각이 달라졌어?"         |
| 내적동기부여       | 보상보다 호기심과 의미 때문에 질문하고 몰입하는 힘.      | 스스로 궁금한 주제로 확장, 같은 주제를 반복 탐색, 깊게 머무름.        | "왜 그게 계속 궁금해?", "이 질문을 더 알아보려면 어떤 책이 좋을까?"      |

# 5. 서비스 전체 플로우 및 대표 시나리오

## 5.1 상위 플로우

서비스의 큰 흐름은 다음 순서로 구성되며, ⑤\~⑦이 매일 반복되는 핵심 루프(Daily Loop), ⑧이 4주 주기 루프이다. 추천 카드 외에도 사용자가 보유한 책을 직접 입력해 자유 선택으로 세션을 진행할 수 있다.

**① 회원가입 → ② 온보딩 설문 → ③ 프로필·페르소나 확인 → ④ 발전 역량 제시 → ⑤ 오늘의 Activity Card → ⑥ 대화식 독서 세션 → ⑦ 세션 피드백 → ⑧ 4주 성장 리포트 → (⑤로 순환)**

|                 |              |                                                                                   |
| --------------- | ------------ | --------------------------------------------------------------------------------- |
| **단계**          | **화면**       | **설명**                                                                            |
| ① 회원가입          | 가입 / 로그인     | 양육자 계정 생성, 보호자 동의(아동 데이터 처리) 수집                                                   |
| ② 온보딩 설문        | 설문 위저드       | 아이 이름·나이·성격·기질, 언어 환경·독서 루틴, 좋아하는 책·집에 있는 책 리스트, 성장 목표, 4대 역량 문항 응답 (5\~7분)       |
| ③ 프로필 확인        | 아이 프로필       | 다이아몬드 그래프·강약점·긍정형 페르소나 제시                                                         |
| ④ 발전 역량 제시      | 역량 제시        | 4대 역량 중 아이가 키워야 하는 역량을 서비스가 제시(양육자 변경 가능)                                         |
| ⑤ Activity Card | 홈            | 매일 아침 역량 순환 기준으로 Activity Card 3장(스와이프) 추천 — 책 + 코칭 문장, 책 선택 시 대화 Prompt 2\~3개 카드 |
| ⑥ 세션            | 세션 화면        | 캐릭터 버블 인사(양육자 대상) → 녹음(일시정지 가능, 경청 인터랙션) → 제출(Submit) 또는 폐기(Discard)                 |
| ⑦ 피드백           | 세션 종료 피드백 카드 | 짧은 회고 + 후기 입력(아이 만족도 스코어링, 아이의 반응 등) — 수집·분석하여 리포트에 반영                            |
| ⑧ 리포트           | 리포트          | 4주 주기 역량 그래프·페르소나 변화·대화 분석을 화면으로 제공, PDF 다운로드                                     |

## 5.2 대화식 독서 세션 하위 프로세스

세션은 다음 4단계 상태로 진행된다(예약·알림은 세션 프로세스에서 제외, 홈 Activity Card의 알림 기능으로 이관). 각 단계의 화면 동작은 7.5에서 상세히 정의한다.

|           |                      |                                                                                                               |
| --------- | -------------------- | ------------------------------------------------------------------------------------------------------------- |
| **단계**    | **상태**               | **주요 동작**                                                                                                     |
| 1\. 세션 준비 | ready                | 세션 진입 시 캐릭터가 메시지 버블로 양육자(엄마)에게 인사하고 리딩 세션·녹음을 유도, 오늘 책 소개. 중앙에 녹음 버튼 표시                                       |
| 2\. 녹음 진행 | recording ⇄ paused   | 녹음 버튼 탭 → "자, 이제 HARU가 함께 대화를 기록할게요" → 녹음 시작, 녹음 버튼이 일시정지(Pause)로 전환되고 하단 "Discard" · "Submit" 버튼이 활성화된다. 일시정지(Pause)/재개 가능. 캐릭터는 듣고 있음을 표시하는 표정·동작만 보여줌 |
| 3\. 세션 종료 | completed (제출) · 세션 정리 (폐기) | "Submit" 탭 → 녹음이 제출되었다는 안내 토스트 → 캐릭터가 버블로 세션 성공 피드백("오늘 책읽기 세션 성공\!") + 출석체크 스티커 → 양육자 피드백 카드. "Discard" 탭 → 녹음을 폐기하고 홈으로 돌아간다(제출·분석 없음)                                      |
| 4\. 분석    | analyzing → analyzed | 녹음 파일 업로드 → STT 전사 → 역량 지표 분석(비동기, 24시간 내). 완료 시 짧은 성장 피드백 알림 및 프로필 반영                                        |

## 5.3 대표 서비스 시나리오 (Day-in-the-Life)

김하루(36) — 5세 딸 Emma. 1차 언어는 영어이므로 캐릭터 버블과 사용자 노출 UI는 영어이며, 아래는 이해를 위한 국문 서술이다.

시나리오 전제: 부모는 아이와 책을 읽는 상황에 들어가기 전 HARU를 통해 오늘의 목적, 책, 질문을 받는다. 독서 중에는 앱이 아이를 대신 가르치지 않고, 부모가 대화를 잘 이어가도록 조용히 돕는다.

1. (Day 1, 가입) 하루는 앱 설치 후 이메일 또는 Google/Apple 계정으로 가입하고, 아동 음성 데이터 처리에 대한 보호자 동의에 체크한다. Emma의 이름·생년월·성격("낯가림이 있지만 그림 그리기를 좋아함")·기질, 언어 환경과 가족 독서 루틴, 좋아하는 책 3권과 집에 있는 책 리스트, 부모가 중요하게 생각하는 성장 목표, 4대 역량 문항에 응답한다. (약 6분)

2. 설문 완료 즉시 Emma의 User Contributed Profile이 생성된다: 4대 역량 다이아몬드 그래프(감정 조절 3.2 / 자기주도 2.5 / 회복탄력성 3.0 / 내적동기 3.8), 강점·보완점 요약, 긍정형 페르소나 "Curious Little Painter — 관찰력이 자라나는 꼬마 화가". 이 그래프는 "잘함/못함"의 판정이 아니라 부모가 관찰한 신호의 분포임을 함께 안내한다. 서비스는 분석 결과를 바탕으로 우선 키울 발전 역량으로 "자기주도"를 제시한다.

3. 홈에 첫 Activity Card 3장이 나타난다: 카드를 스와이프로 넘겨보며 고를 수 있고, 각 카드에 추천 책 — 『The Most Magnificent Thing』 표지, 추천 이유("스스로 시도하고 실패해도 다시 도전하는 이야기예요"), 부모가 기억할 코칭 문장 1개("답을 알려주기보다, 아이의 시도를 소리 내어 읽어주세요")가 표시된다. 책은 증정 받은 라이브러리 중에서 추천되며, 엄마와 아이가 함께 책을 고르면 다음 카드에 해당 책의 대화 Prompt 2\~3개("What would YOU build?", "How did she feel when it broke?")가 제시된다.

4. 하루는 카드에서 읽을 Context로 "Bedtime (9:00 PM)"을 선택한다. (지금 시작 / 잠자리 전 / 유치원 하원 후 / 주말 아침 / 차 안에서 짧게 — 선택한 상황에 맞춰 알림 문구와 대화 톤이 조정된다)

5. 밤 8시 55분, 초대형(invitational) 푸시 알림이 도착한다: "Emma와 책 읽어볼까요? 오늘은 스스로 해내는 이야기예요 📖" 알림을 탭하면 세션 화면으로 진입한다.

6. 세션 화면: 상단의 HARU 캐릭터가 메시지 버블로 엄마에게 인사하고 리딩 세션을 유도한다("Emma와 오늘의 이야기, 시작해 볼까요?"). 엄마가 "Yes\!"를 탭하면 캐릭터가 짧은 버블로 반응하고, 화면 중앙의 큰 녹음 버튼이 살짝 튀며 시작을 유도한다.

7. 하루가 녹음 버튼을 탭하면 "자, 이제 HARU가 함께 대화를 기록할게요(Now HARU is recording your storytime)" 메시지와 함께 녹음이 시작되고, 녹음 버튼은 일시정지(Pause)로 바뀌며 하단의 "Discard" · "Submit" 버튼이 활성화된다. 녹음은 감시가 아니라 소중한 대화 시간을 기록하는 행위로 느껴지도록 디자인한다. 필요 시 일시정지(Pause)할 수 있다.

8. 책을 읽는 동안 캐릭터는 발화나 버블 개입 없이, 듣고 있다는 표정과 작은 동작(고개 끄덕임 등)만 보여준다. 하루는 세션 전에 확인한 Prompt를 떠올려 자연스럽게 질문을 던지고, 필요하면 하단의 "Prompt 모아보기" 버튼으로 질문을 조용히 다시 확인한다.

9. 책을 다 읽고 "Submit"을 엄마가 탭하면 녹음이 제출되었다는 안내 토스트가 뜨고, 캐릭터가 버블로 "오늘 책읽기 세션 성공\!" 피드백을 주며 출석체크 스티커를 받는다. 기록을 남기고 싶지 않으면 "Discard"로 녹음을 폐기하고 홈으로 돌아갈 수 있다.

10. 이어서 양육자용 피드백(회고) 카드가 표시된다: "오늘 아이와 책 읽기는 어떠셨나요?" — 별점과 함께 아이의 반응, 감정 표현, 질문 여부, 집중 시간, 어려웠던 점을 간단히 체크하고, 다음 카드에서 다시 이야기하고 싶은 주제와 자유 후기를 입력한다. 입력 내용은 수집·분석되어 4주 리포트에 반영된다. (선택 사항, 30초)

11. 녹음은 백그라운드에서 업로드·전사·분석되고, 분석이 끝나면 짧은 성장 피드백이 도착한다: "오늘 Emma는 감정 단어를 3번 사용했어요. 'proud'라는 새로운 단어도 나왔어요." 다음 날 홈의 Activity Card는 역량 순환 스케줄에 따라 갱신된다. (예: "오늘은 감정 조절 데이\! 『The Color Monster』 — 감정을 색깔로 이야기해 보는 책이에요")

12. (Day 30) 발행 기준(누적 녹음 1시간 이상, 세션 2\~3회 이상)을 충족하면 "Emma의 Profile Report가 도착했어요" 메시지 버블 알림이 온다. 탭하면 4주간의 세션 분석 리포트가 열린다: 다이아몬드 그래프 변화(자기주도 2.5 → 2.9), 페르소나 히스토리("Curious Little Painter" → "Brave Little Maker"), 발화량·감정 어휘·차례 주고받기(turn-taking) 지표, 최근 대화 신호와 인상적인 발화 인용. 리포트는 화면으로 보여주고 PDF로 다운로드할 수 있다.

# 6. 정보 구조 및 내비게이션

## 6.1 내비게이션 구조

하단 내비게이션은 서재·세션·리포트 3탭으로 구성한다. 중앙의 "세션" 버튼은 말해보카 스타일로 크고 둥근 강조 버튼으로 배치하며, 홈은 기본 메인 화면(상단 집 모양 아이콘), 설정은 상단 아이콘으로 진입한다.

|                                |                                                    |
| ------------------------------ | -------------------------------------------------- |
| **영역**                         | **역할 / 연결 화면**                                     |
| 홈 — Default Main (상단 집 모양 아이콘) | 오늘의 Activity Card, 예정된 세션 알림, 연속 기록(streak)        |
| 서재 (Library) — 하단 탭            | 증정·보유 책 라이브러리, 보유 책 직접 등록, 읽은 책 히스토리, 책별 Prompt 보기 |
| 세션 — 하단 탭 중앙 강조 버튼             | 대화식 독서 세션 시작 — 캐릭터 + 중앙 녹음 버튼 화면                   |
| 리포트 — 하단 탭                     | 다이아몬드 그래프 현황, 4주 리포트 아카이브, 페르소나 히스토리               |
| 설정 (상단 아이콘)                    | 아이 프로필 수정, 알림 시간, 계정·구독, 데이터 관리(음성 삭제)             |

## 6.2 화면 맵

  - 인증 — 회원가입 / 로그인 / 비밀번호 재설정 / 보호자 동의 (Trial 체험 시작 후 가입 전환 허용)

  - 온보딩 — 프로필 화면(아이 정보 확인·보완) → 설문 위저드 4단계(Reading together → Books and interests → Growing together → Capability) → 프로필 결과 → 발전 역량 제시. 설문은 **한 카드에 한 문항**을 제시하는 카드 덱이다.

  - 홈 — 오늘의 Activity Card / 세션 Context 선택 / streak·보상 현황

  - 세션 카드 — 세션 준비(캐릭터 버블 인사) → 녹음(일시정지 가능, 경청 인터랙션) → 제출(Submit) → 피드백·후기 카드 (폐기 시에는 홈으로 복귀)

  - 리포트 — 역량 현황 / 4주 리포트 상세 / PDF 다운로드

  - 설정 — 아이 프로필 / 알림 / 계정·구독 / 음성 데이터 관리

# 7. 화면별 상세 명세

## 7.1 회원가입 · 로그인

### 구성 요소

  - 이메일·비밀번호 가입, 소셜 가입(Apple / Google — 모바일 필수)

  - 이용약관·개인정보처리방침 동의(필수), 아동 음성 데이터 수집·처리에 대한 보호자 동의(필수, 별도 체크), 마케팅 수신(선택)

  - 로그인 상태 유지, 비밀번호 재설정(이메일 링크)

  - 아이 이름·생년월·성별(선택)을 가입 화면에서 함께 입력받는다. **단 이 값은 보호자 동의가 기록되기 전까지 서버로 전송하지 않는다** — 기기에만 보관했다가 동의 이후 1회로 전송한다.

### 규칙 / 예외

  - 보호자 동의 미체크 시 가입 진행 불가(아동 프라이버시 규정 준수의 전제 조건).

  - 가입 완료 시 Free 플랜 자동 부여 후 온보딩 설문으로 즉시 이동.

  - Trial(체험) 시작 후 가입 전환 흐름을 허용한다(온보딩 설문까지 체험 → 프로필 저장 시 가입 유도).

  - **동의 전 아동 데이터 미전송 원칙은 유지된다.** 가입 화면이 아이 정보를 입력받는 것과, 그 값을 서버로 보내는 것은 분리된다.

## 7.2 온보딩 설문 (User Contributed Profile 수집)

목적: 첫 추천의 재료가 되는 아이 정보를 부담 없게 수집한다. 아이를 단번에 평가하는 것이 아니라, 부모가 제공한 정보로 초기 프로필을 만드는 단계임을 안내한다. 진행바 표시, 중도 이탈 시 이어서 진행 가능.

소요 시간은 **문항 구성에서 파생되는 값**이며 PRD 가 고정 수치를 명시하지 않는다(프로필 약 1분 + 설문 약 3분 수준). 문항이 바뀌면 안내 문구도 따라 바뀌어야 하므로, 화면 문구에 숫자를 하드코딩하지 않는다.

### 구성 요소

온보딩은 **프로필 화면 1개 + 설문 4단계**로 구성한다. 설문 4단계는 모두 같은 카드 디자인을 쓰고 **상단 제목만 바뀌며, 한 카드에 한 문항**을 제시한다.

  - 프로필 화면 (About your child) — 가입에서 받은 **이름·생년월·성별을 표시**하고(수정 가능), 관계·언어 환경·가족 내 독서 루틴을 입력받는다

  - 1단계 Reading together — 이야기 자극 선호, 읽어 주는 동안의 모습. **관찰 가능한 행동**을 묻는다

  - 2단계 Books and interests — 관심 영역 태그, 이미 잘 아는 책(큐레이션 목록에서 선택), 좋아하는 책 제목 직접 입력

  - 3단계 Growing together — 부모가 함께 키우고 싶은 것(4대 역량 중 선택)

  - 4단계 Capability — 4대 역량 관찰 문항, 역량별 동일 문항 수, 리커트 척도(양육자 관찰 기준)

### 규칙 / 예외

  - 좋아하는 책이 자체 DB에 없으면 제목 텍스트로 저장하고 추천 로직에는 주제 태그만 사용. **온보딩에서 책 검색 기능은 제공하지 않는다** — 제목 직접 입력만 받으며, 큐레이션 책 선택은 "이미 잘 아는 책" 문항이 담당한다. 책 검색은 Library(§8.1) 소관이다.

  - **"집에 있는 책 리스트" 입력은 폐지한다.** 같은 목적(이미 보유·숙지한 책)을 "이미 잘 아는 책" 문항이 더 정확하게 수집한다 — 자유 입력은 책 ID 로 매칭할 수 없기 때문이다.

  - 설문 카드에는 하단 확정 버튼을 두지 않는다. 스와이프 또는 선택으로 진행하며, 마지막 카드에서만 제출한다.

  - 설문 완료 시점에 프로필 산출은 즉시(룰 기반 스코어링), LLM 페르소나 문구 생성은 3초 내 응답 목표.

## 7.3 아이 프로필 · 페르소나 화면

### 구성 요소

  - 4대 역량 다이아몬드(레이더) 그래프 — 역량별 1.0\~5.0 스코어. "잘함/못함"의 판정이 아니라 현재 부모가 관찰한 신호의 분포임을 화면에 명시

  - 강점·보완점 각 2개 요약 문구 — 강점을 먼저 드러내고 다음 성장 방향을 부드럽게 안내

  - 페르소나 카드 — 일러스트 배경 + 페르소나 명칭 + 2\~3문장 설명(예: "조용히 관찰하지만 깊게 느끼는 아이"). 명칭·설명은 반드시 긍정적·발전적 단어만 사용(8.4 생성 규칙 참조)

  - 발전 역량 제시 — 서비스가 분석 결과를 바탕으로 키워야 할 역량을 제시하며, 양육자는 다이아몬드 그래프의 축을 탭해 변경할 수 있다

### 규칙 / 예외

  - 제시된 발전 역량은 언제든 설정에서 변경 가능하며, 기본 제시값은 최저 스코어 역량이다.

  - 프로필은 세션 분석이 누적될 때마다 자동 업데이트되며, 변경 이력은 리포트의 히스토리에 보존.

## 7.4 홈 — 오늘의 Activity Card

매일 아침 7시(설정 가능)에 오늘의 Activity Card가 갱신된다. 카드 UI는 VROOM Tip Card 스타일을 참고한 풀폭 카드 3장 스와이프 덱(오늘의 추천 + 대안 2장)으로 구성한다. 매일 새로운 과제를 주는 것이 아니라, 부담 없이 반복할 수 있는 작고 구체적인 대화 루틴("오늘 바로 할 수 있는 질문")을 제공한다.

### 구성 요소

  - 역량 배지 — **덱 카드마다 해당 카드의 역량을 표시**한다. 하루 1개의 "오늘의 역량"이 아니라 카드별 역량이며, "오늘은 ~의 날" 형태의 문구는 쓰지 않는다

  - 추천 책 — 표지 이미지, 제목, 추천 이유("왜 이 책인지") 1\~2문장

  - 부모용 코칭 문장 — 부모가 기억할 짧은 코칭 문장 1개(예: "답을 알려주기보다 아이의 시도를 읽어주세요")

  - 책 선택 — 증정 받은 책 라이브러리 중에서 엄마와 아이가 함께 선택(보유한 책 직접 입력·선택도 가능)

  - 대화 Prompt 미리보기 — **책을 선택하기 전에 카드 안에서 바로 보인다**(선택 후 다음 카드가 아니다). "이 책을 읽어 줄 때 이런 질문을 해보세요" (세션 중 자동 제시는 없으므로, 세션 전에 확인하는 것이 기본 흐름)

  - Prompt 표시 개수는 접힌 상태에서 3개 내외이며 **상한이 아니다**. 그 이상은 확장으로 도달한다. 개수 상한은 서버가 정하고 클라이언트는 잘라내지 않는다

  - Prompt 단계 표시 — 읽기 전/읽은 후 구분과 책 페이지 참조를 배지로 표시할 수 있다. 값이 없으면 표시하지 않는다

  - Context 선택 — 지금 시작 / 잠자리 전 / 유치원 하원 후 / 주말 아침 / 차 안에서 짧게 / 직접 시간 선택. 선택한 상황에 맞춰 알림 문구와 대화 톤을 조정

  - 보조 요소 — **이번 주 세션 수**, 지난 세션의 아이 하이라이트 한 줄. 집계 창은 "이번 주"이며 Progress 화면과 같은 기준이다. 연속 일수(streak)는 표시하지 않는다

### 규칙 / 예외

  - 책은 자체 서비스 DB(증정·보유 라이브러리)를 우선 참조하고, 주어진 책 내에서 추천한다. 같은 책의 반복 읽기를 지원하며, 재추천 시에는 새로운 Prompt 세트를 제시한다.

  - 선택한 Context가 시간 미지정형(예: 하원 후)이면 학습된 평균 시간대로 알림을 발송한다. 알림 문구는 명령형이 아닌 초대형(invitational)으로 작성한다.

  - 라이브러리 책을 보유하지 않은 경우 증정 신청 버튼을 제공하고, 도착 전에는 "책 없이 대화만 하기" 옵션으로 대화 전용 세션을 지원한다.

## 7.5 세션 화면 (핵심 화면)

말해보카의 레이아웃을 참고한다: 상단 캐릭터·말풍선 영역, 중앙 하단의 큰 원형 녹음 버튼, 그 아래 세션 액션 버튼("Discard" · "Submit"), 그리고 "Prompt 모아보기" 보조 진입. 캐릭터는 Ello 스타일의 친근한 캐릭터로, 세션의 시작·종료 리추얼을 담당한다. 캐릭터의 커뮤니케이션은 메시지 버블(텍스트)로 하며, MVP에서는 TTS 음성 발화를 하지 않는다. 독서 중에는 앱이 아이를 대신 가르치지 않는다.

### 상태별 동작

|        |                                                                                       |                                                                                           |
| ------ | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **상태** | **캐릭터**                                                                               | **화면 / 버튼**                                                                               |
| 세션 준비  | 메시지 버블로 양육자(엄마)에게 인사, 리딩 세션·녹음 유도 + 오늘 책 소개 (예: "Ready for today's story with Emma?") | 중앙 녹음 버튼 표시(라벨 "Tap to recording", 맥동 애니메이션), 상단에 오늘의 책 카드. 하단 "Discard" · "Submit" 버튼은 **비활성**                                                      |
| 녹음 중   | 듣고 있음을 표시하는 표정·동작만 표시(발화·버블 없음)                                                       | 녹음 버튼 → 일시정지(Pause) 버튼으로 전환, 하단 "Discard" · "Submit" 버튼 **활성화**. 일시정지/재개 가능. "Prompt 모아보기"로 세션 전 받은 질문을 다시 확인 가능 |
| 제출(Submit)  | 버블로 세션 성공 피드백 — "오늘 책읽기 세션 성공\!" (사전 검수 템플릿)                                          | 녹음이 제출되었다는 안내 토스트 → 완료 애니메이션 + 출석체크 스티커 지급 → 피드백 카드로 전환                                                       |
| 폐기(Discard)  | 별도 버블 없음                                          | 해당 세션의 녹음을 폐기하고 홈으로 돌아간다. 제출·분석·스티커 없음. 폐기는 되돌릴 수 없다                                                       |

### Prompt 확인 방식

  - 대화 Prompt 2\~3개는 세션 시작 전 Activity Card 흐름에서 확인하는 것이 기본이다. 세션 중 자동 제시는 하지 않는다(아이 몰입·대화 방해 금지).

  - 세션 중에는 "Prompt 모아보기" 버튼으로 양육자가 필요할 때만 조용히 확인한다(무음·무진동).

  - Prompt 문구는 양육자가 그대로 소리 내어 읽을 수 있는 완성형 질문으로 제공한다. 실시간 침묵 감지 기반 자동 제시(조용한 코치 모드)는 MVP 이후 검토한다(7.9).

### 규칙 / 예외

  - 캐릭터 버블은 세션 시작·세션 종료 2가지 경우로 제한한다(녹음 중 개입 없음). 책 읽기의 주인공은 양육자와 아이이며, 캐릭터는 "함께 듣는 친구" 포지션을 유지한다.

  - 캐릭터 버블 문구는 사전 검수된 템플릿 + 안전 필터를 통과한 개인화 슬롯(아이 이름, 책 제목)만 조합한다. 자유 생성 문구와 TTS 음성 발화는 MVP에서 하지 않는다(11장 콘텐츠 안전 참조).

  - 세션은 최대 30분에서 자동 종료(녹음 보존), 백그라운드 전환 시 녹음은 유지된다.

## 7.6 세션 종료 · 피드백(회고)

  - "오늘 아이와 책 읽기는 어떠셨나요?" 질문 버블과 함께 피드백 카드 표시: 별점(1\~5) + 체크 항목(아이의 반응 / 감정 표현 / 질문 여부 / 집중 시간 / 어려웠던 점) + 다음에 다시 이야기하고 싶은 주제(선택).

  - 피드백 카드 다음 카드에서 부모가 자유 후기를 입력할 수 있다. 입력된 피드백·후기는 수집·분석되어 4주 리포트(부모 피드백 요약)에 반영된다.

  - 피드백은 추천 로직의 신호로도 사용(예: "힘들어했어요" 체크 → 다음 추천 난이도 하향, "다시 이야기하고 싶은 주제" → 다음 Prompt에 반영).

  - 분석 완료 시 짧은 성장 피드백 알림 제공 — 사용한 단어·감정 어휘 등 1\~2줄 요약(예: "오늘 Emma는 감정 단어를 3번 사용했어요").

  - 아이용 보상: 세션 완료 시 출석체크 스티커 1개 지급(스티커로 아바타의 방(Room)을 꾸미는 수집 요소는 MVP 이후, 7.9 참조).

## 7.7 리포트 (4주 주기)

### 발행 기준

  - 주기: 4주(월 1회). 발행 조건: 해당 주기에 누적 녹음 1시간 이상 + 녹음 세션 2\~3회 이상.

  - 예시: 4주간 세션 6회·누적 녹음 85분 → 정상 발행. 세션 2회·누적 40분 → 발행 조건 미충족으로 다음 주기로 이월하고 세션 독려 알림을 발송한다.

### 구성 요소

  - 발행 알림 — "\[아이 이름\] Profile Report가 도착했어요" 메시지 버블. 탭하면 리포트 상세로 이동.

  - 역량 변화 — 다이아몬드 그래프 이전/현재 오버레이, 역량별 스코어 변화와 근거 설명.

  - 페르소나 히스토리 — 기본 Profile + Contributed Profile 기반 페르소나의 변화 타임라인.

  - 대화 분석 — 세션 수, 총 대화 시간, 아이 발화량, 차례 주고받기(turn-taking) 횟수, 감정 어휘 사용, 최근 대화 신호, 인상적인 발화 인용 1\~2개.

  - 부모 피드백 요약 — 세션 피드백 카드·후기 입력을 수집·분석한 관찰 요약(체크 항목 추이, 자주 언급된 주제).

  - PDF 다운로드 — 종합 리포트를 화면으로 제공하고 PDF로 저장·공유(조부모·배우자 공유 용도).

### 규칙 / 예외

  - 리포트는 진단서가 아니라 부모가 아이를 더 잘 이해하기 위한 Parenting Intelligence 문서다. 분석 문구는 항상 성장 관점의 긍정 프레임으로 작성하고, 또래 비교·서열화·진단성 표현은 금지한다.

## 7.8 설정

  - 아이 프로필 수정(설문 문항 재응답 포함), 발전 역량 변경

  - 알림 — Activity Card 갱신 시간, 세션 리마인더 시간·요일

  - 계정·구독 — 요금제 확인/변경(9장), 로그아웃, 탈퇴

  - 데이터 관리 — 녹음 원본 보관 정책 안내, 세션별 녹음 삭제, 전체 데이터 삭제 요청(아동 데이터 삭제권)

## 7.9 UX 개선 제안 — 하이라이트 클립·카드 덱은 MVP 포함, 아바타의 방·조용한 코치 모드는 MVP 이후

말해보카(레이아웃)·Ello(캐릭터)·VROOM(Tip Card)을 기반으로 하되, 다음 4가지를 추가 제안한다.

  - \[MVP 포함\] 세션 하이라이트 오디오 클립 — 분석 시 아이의 인상적인 발화 10\~15초를 자동 추출해 리포트에 첨부. "성장을 눈으로 확인"을 넘어 "귀로 확인"하게 하며, 가족 공유를 통한 바이럴 요소로도 작동.

  - \[MVP 포함\] 카드 덱 스와이프 — 오늘의 Activity Card를 1장 강제가 아닌 3장 덱(오늘의 추천 + 대안 2장)으로 제공, 좌우 스와이프로 선택. 양육자에게 통제감을 주면서 추천 채택률 데이터를 확보.

  - \[MVP 이후\] 아바타의 방(Room) 성장 보상 — 세션을 완료할 때마다 아바타가 사는 방에 가구·창문·식물이 하나씩 생기는 수집형 보상. 역량별로 다른 오브젝트가 생겨 아이의 성장이 공간의 성장으로 시각화된다.

  - \[MVP 이후\] 조용한 코치 모드 — Prompt 버블을 화면 하단(양육자 시선 높이)에 무음 고정 표시하고 아이 쪽 시야의 아바타 영역과 분리하는 이중 레이어 UX.

# 8. 콘텐츠 · 추천 요구사항

## 8.1 책 라이브러리

  - MVP 기준 초기 20권 규모의 추천용 큐레이션 책 라이브러리를 구축한다(예: 3세용 — Dear Zoo, Brown Bear, The Very Hungry Caterpillar 등. 연령별 리스트는 별도 부록으로 관리), 1차 언어 영어.

  - 메타데이터: 제목, 저자, 표지, 대상 연령, 주제 태그, 4대 역량 관련도 스코어, 난이도, 예상 읽기 시간, 구매 링크.

  - 증정 프로그램 — 사용자가 라이브러리 책을 보유하지 않은 경우 신청을 받아 실물 책을 증정(B2B 라이선스 기반 주문·배송)하여 실제로 보유할 수 있도록 유도하고, 구매 링크를 함께 제공한다.

  - 온보딩에서 수집한 집에 있는 책 리스트를 추천 대상에 포함하고, DB에 없는 책은 제목 직접 입력으로 등록해 범용 Prompt·대화 전용 세션으로 지원한다.

## 8.2 대화 Prompt 라이브러리

  - Prompt는 역량 × 연령대(3-4 / 5-6 / 7-9) × 책(또는 범용) 매트릭스로 구성하고, 책별 최소 6개를 보유한다. 한 번에 제시하는 개수(2\~3개 내외)는 **서버의 생성 정책**이며 클라이언트 검증 조건이 아니다. 각 세트는 질문 + 부모용 코칭 문장 + Follow-up 질문으로 구성한다.

  - 각 Prompt 는 **읽기 전/읽은 후 단계**와 **책 페이지 참조**를 선택적으로 가질 수 있다. 페이지 참조는 책별 페이지 단위 앵커 데이터를 전제하므로 콘텐츠 제작 범위에 포함된다.

  - 개방형 질문 원칙: 예/아니오로 답이 끝나지 않는 질문("How did she feel?", "What would you do?")으로 작성. 4장의 역량별 추천 대화 방향을 설계 기준으로 사용한다.

  - 전문가(아동 발달) 감수를 거친 템플릿 기반으로 하고, LLM은 책·아이 맥락에 맞는 슬롯 변형에만 사용.

## 8.3 추천 로직

  - Cold Start(가입\~세션 3회): User Contributed Profile(설문) 기반 — 제시 역량 우선, 선호 주제 태그 매칭.

  - Warm(세션 4회\~): 세션 분석 결과를 결합 — 피드백 체크 항목, 아이 발화 반응이 좋았던 주제, 역량 스코어 변화 반영.

  - 역량 순환 스케줄: **덱의 카드마다 다른 역량을 배치**하여 4대 역량이 고르게 다뤄지도록 한다. 날짜 단위로 하루 1개 역량을 배정하지 않는다.

  - 같은 책의 반복 읽기를 지원한다 — 재추천 시 책 내용 + 누적 대화 분석을 기반으로 새로운 Prompt 세트를 랜덤 구성한다(예: 같은 책 1회차 "What will he eat next?" → 2회차 "Why was he still hungry?" → 3회차 "What's your favorite food?"). 동일 주제 연속 3일 편성은 지양.

## 8.4 페르소나·리포트 언어 규칙

  - 페르소나 명칭·설명은 긍정적이고 발전적인 단어만 사용한다(예: "Brave Little Maker", "조용히 관찰하지만 깊게 느끼는 아이"). 결핍·부정·비교 표현(산만한, 느린, 뒤처진 등)은 금지어 사전으로 차단.

  - 서비스 전반에서 부족·진단·장애 대신 관찰, 신호, 성장 힌트, 다음 대화 방향의 언어를 사용한다. 보완점 서술은 "자라날 부분(growing edge)" 프레임으로 표현한다.

  - 생성 문구는 안전 필터 + 금지어 검증을 통과해야 노출되며, 실패 시 사전 검수된 기본 페르소나 풀에서 대체.

## 12.2 세션 상태

**ready(세션 준비) → recording(녹음 중) ⇄ paused(일시정지) → completed(제출 완료) → analyzing(분석 중) → analyzed(분석 완료) / failed(분석 실패 — 재시도 대상)**

녹음 중·일시정지 상태에서 "Discard"를 선택하면 해당 세션은 **completed 로 가지 않고 정리**된다 — 녹음은 제출·분석하지 않고 기기에서 삭제하며, 양육자는 홈으로 돌아간다. 정리된 세션을 방치 세션(10분 미시작, §13)과 **같은 정리 상태로 표기할지 별도 상태를 둘지는 기술 설계에서 확정**하며, 어느 쪽이든 **왜 끝났는지(방치 / 사용자 폐기)는 구분해 기록**한다.

## 14.2 가정 및 위험

  - \[가정\] 타겟 가정은 실물 그림책을 보유하고 있거나 증정 프로그램·도서관 이용이 가능하다. → 검증 실패 시 "대화 전용 세션" 비중 확대.

  - \[위험\] 아동 음성 STT 정확도 — 취학전 아동 발화는 인식률이 낮다. 분석 지표는 정확한 전사보다 발화량·turn-taking 등 강건한 지표 중심으로 설계한다.

  - \[위험\] 아동 프라이버시 규제(COPPA 등) — 보호자 동의·데이터 파기 정책을 출시 전 법률 검토 필수. 신뢰 장벽을 낮추는 언어(Parent Insight 등) 일관 적용.

  - \[위험\] 캐릭터 애착 형성 — 텍스트 버블만으로는 세션 리추얼의 매력이 약할 수 있다. 표정·모션 인터랙션 품질로 보완하고, TTS 음성 발화는 베타 반응 검증 후 도입을 검토한다.

  - \[위험\] 리포트 신뢰성 — 세션 수가 적은 초기에 과잉 해석 금지. 발행 기준 미충족 시 다음 주기로 이월(7.7).

  - \[위험\] 책 증정 프로그램 — B2B 라이선스 협상·물류 비용이 MVP 일정의 병목이 될 수 있다. 초기에는 소량 큐레이션(연령별 20권)으로 시작.

  - \[미결\] "AI"를 브랜드 전면에 내세울지 여부 — AI Storytime Coach로 포지셔닝할지, AI를 드러내지 않는 Parenting Coach로 갈지 마케팅 톤 결정 필요.
